# 生态采材与工坊用料服务（craft-provenance）

为桦树皮工艺合作社管理**生态采材许可、采材合规判定、材料隔离、工坊用料守恒与公开验真**。
`contracts/craft_record.json` 保存公开的领域样例，用来约定外部数据的名称与层级；样例不含真实个人资料、业务凭据或敏感林点坐标。

## 核心规则

1. **林地规则版本化**：管理者发布林地的可采网格、树龄条件、季节窗口、单株上限、恢复观察要求。
   修订产生新版本，**只约束生效日之后的采集**；已使用材料永远按采集当时的规则版本接受审计。
2. **许可与并发申领**：一张许可有总量上限。多个采集队并发申领时，"查余额—扣减"单次同步完成，
   超量申请返回 `409 quota_exceeded`，总量绝不被突破。
3. **弱网采材**：采集队离线生成 `record_id` 记录采材（可只传网格编号，也可传坐标——服务端入库前
   再次模糊化，**从不持久化精确坐标**）与树体处置方式；联网后按批次同步，批次与记录双重幂等，
   乱序送达、重复重放都不重复计账。
4. **合规判定与隔离**：证照有效期、季节窗口、林地网格越界、树龄、单株上限、申领余额逐项校验；
   任一项不通过的材料进入**隔离账**（`GET /quarantine`），禁止交接、禁止投产。恢复观察不合格的
   已入库材料也会被追转入隔离。
5. **恢复观察**：要求恢复的林地，采材自动生成观察任务；只有恢复检查完成的材料才能交接与投产。
6. **用料守恒**：`投料 = 净入作 + 边角料`；边角料可回收再投入其他作品；整料可退库再分配。
   多人合制的制作者份额之和必须为 1。
7. **溯源去重**：从任一作品沿凭证回溯，同一采材凭证即使经边角料跨作品流转，也只计一次。
8. **公开验真**：`GET /v/works/{id}` 只给来源结论与粗粒度信息，不含网格、林地编号、证照号、许可号。
9. **月报核对**：管理者按林地 + 月查看实际消耗、退料、未闭环边角料、恢复任务与许可剩余额度，
   报表自带守恒校验。

## HTTP API

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/admin/teams` | 登记采集队与采集证照（有效期） |
| POST | `/admin/forests` | 发布林地与首版采材规则 |
| POST | `/admin/forests/{id}/revisions` | 修订规则（新版本，只约束后续采集） |
| POST | `/admin/licenses` | 基于某规则版本发放总量许可 |
| POST | `/claims` | 采集队申领额度（需 `request_id` 幂等键，并发安全） |
| POST | `/harvests/sync` | 弱网采材批次同步（幂等） |
| POST | `/recovery/checks` | 记录树体恢复观察结果 |
| POST | `/handovers` | 合规材料交接给工坊（恢复未完成不得交接） |
| POST | `/works` | 工坊把合规材料分配到作品（支持多人合制、边角料） |
| POST | `/scraps/reuse` | 边角料回收再投入另一作品 |
| POST | `/returns` | 整料退库（可再次分配） |
| GET | `/works/{id}/trace` | 从作品追到无重复计算的采材凭证 |
| GET | `/v/works/{id}` | **公开验真**（仅结论，不含敏感林点） |
| GET | `/reports/forests/{id}/months/{YYYY-MM}` | 林地月度核对报表 |
| GET | `/quarantine` | 隔离材料清单（含原因） |
| GET | `/licenses` | 许可额度余额 |
| GET | `/health` | 服务标识 |

## 运行

```bash
npm run check           # 服务身份检查
npm test                # 领域契约与 HTTP 测试
node src/service.js --store data/ledger.jsonl --port 8000
# 也可用环境变量 STORE_FILE 指定命令日志
```

所有写操作以命令形式顺序追加到 JSONL；服务重启时重放命令日志即可完整重建台账。
